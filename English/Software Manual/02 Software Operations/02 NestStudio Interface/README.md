## NestStudio Interface

The NestStudio software primarily consists of four functional modules: **Home**, **Prepare**, **Preview**, and **Device**. Within the **Prepare** module, two modes are available: 3D, and 4-Axis. The software defaults to the 3D layout interface upon startup.

* **3D Mode**: Used for conventional machining of three-dimensional models.
* **4-Axis Mode**: Used for 4-axis simultaneous or fixed-axis (indexed) machining.
