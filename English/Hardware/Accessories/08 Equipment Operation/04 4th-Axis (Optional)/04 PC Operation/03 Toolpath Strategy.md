#### Toolpath Strategy

In Toolpath Strategy, users can select 01 Rotation Relief and set the related parameters in the Rotation Relief window.

**Table 8-1 Toolpath Strategy** <!-- mdwb:table id=d7d537dc02349450 -->

| Parameter               | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| ----------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Plunge Angle            | Includes three options: 90° Vertical, 5° Ramp, and 20° Ramp.<br>90° Vertical: The tool plunges vertically into the stock. Suitable for roughing large flat relief areas and helps reduce the risk of tool breakage.<br>5° Ramp: The tool enters the stock at a small ramp angle to reduce cutting impact. Suitable for shallow relief patterns.<br>20° Ramp: The tool enters the stock at a larger ramp angle to reduce tool load. Suitable for deep relief machining and hard materials. |
| Safe Height (mm)        | The safe clearance height to which the tool retracts before moving, preventing collisions with the stock during rapid transits.                                                                                                                                                                                                                                                                                                                                                           |
| Spindle Speed (RPM)     | The spindle rotation speed per minute. In general, a higher spindle speed is recommended when using a smaller tool diameter.                                                                                                                                                                                                                                                                                                                                                              |
| Feed Rate (mm/min)      | The feed speed during relief toolpath movement. A higher value increases machining speed but may result in a rougher surface.                                                                                                                                                                                                                                                                                                                                                             |
| Plunge Rate (mm/min)    | The speed at which the tool moves vertically into the stock.                                                                                                                                                                                                                                                                                                                                                                                                                              |
| Cut Depth Per Pass (mm) | The cutting depth for each pass.                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| Step Over (mm)          | The lateral spacing between adjacent toolpaths. A smaller value produces smoother relief patterns but increases toolpath calculation time.                                                                                                                                                                                                                                                                                                                                                |




> [!note] Note  
> At least one tool must be installed before generating a relief toolpath. For better machining results, use separate tools for roughing and finishing.
