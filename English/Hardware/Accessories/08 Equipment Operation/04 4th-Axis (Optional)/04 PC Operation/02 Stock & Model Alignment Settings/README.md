#### Stock & Model Alignment Settings

In Stock & Model Alignment Settings, users can set the model position along the stock direction through Quick Alignment. After the parameters in the right-side panel are adjusted, the model position in the 3D workspace will update accordingly.

When the alignment mode is switched, the software automatically translates the model. It does not scale or rotate the model, and it does not change the model’s original dimensions.

For batch machining of long bar stock, Center Alignment is recommended. For single-side machining, Left Alignment or Right Alignment can be selected to reserve space for clamping.

> [!note] Note  
> After setting the alignment mode, make sure the entire model is within the stock boundary. If the model extends beyond the stock boundary, an overcut error may be reported when generating the toolpath.
