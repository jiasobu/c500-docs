## About This Guide

This guide is intended for first-time NestWorks C500 users. It covers the basic workflow from creating a project, importing a model, configuring machining parameters, and generating toolpaths to setting the workpiece coordinate system, starting machining, and monitoring the process.

Before machining, complete machine installation, connection, and self-check, and read the safety requirements in the C500 Machine Operation Manual. Refer to the C500 Software Operation Manual for detailed software instructions.
