### Machine Zero Return

Machine zero return is a fundamental calibration function that drives all axes back to the machine’s mechanical reference origin. The system identifies the origin reference position, recalibrates the three-axis mechanical coordinates, and establishes the machine's overall motion coordinate system. After a power cycle or unexpected stop, axis position references may be lost. 
Performing a machine zero return relocks the mechanical origin, restores coordinate accuracy, and ensures subsequent movements, tool offsets, and machining dimensions are precise.
