## Work Origin

Before machining, set the work origin according to the actual workpiece clamping position to ensure that the machine's work coordinates match the origin used in the machining program.

Work origin setting is divided into fully automatic centering and semi-automatic centering.


| **Centering Method** | **Interface Selection**   | **Function Description**                                  |
| :------     | :-------- | :------------------------------------------------                                  |
| Fully Automatic Centering  | Probe | The camera identifies the workpiece and automatically sets the origin.    |
| Semi-Automatic Centering  | Manual | Manually find the edge, then use the probe to set the origin.             |
