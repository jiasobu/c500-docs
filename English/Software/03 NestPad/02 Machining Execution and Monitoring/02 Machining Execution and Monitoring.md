## Machining Execution and Monitoring

On the home page, tap **Files** to access the file management page. The page is divided into three tabs: Local, USB and Collections, each corresponding to a different source of machining files:

- Local: Stores machining files imported to the device's local storage.
- USB: Reads machining files from an external USB drive.
- Collections: Allows you to view files saved to your cloud favorites after logging in to your account.

**Page Operation Instructions**

|    **Function**  |   **Description**   |
|   :---------------   |   :------------------  |
|   Storage Capacity  |   The upper-right corner of the page displays real-time storage usage.  |
|   File Operations   |   Select a file to preview its machining information. You can delete the file or start machining directly. After machining starts, the page automatically switches to the machining interface.   |
|   Supported File Formats  |   The device supports common CNC machining file formats, including `.nc`, `.gcode`, and `.txt`.   |
