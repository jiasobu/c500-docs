### NestPad Access

Users can use **My Collections** on the Control Panel to find saved projects and start machining quickly.

1. Click **Collections** to see your list of bookmarked projects.

![](assets/NestPad_Access_01-db83d3c9573d.png){width=12cm}

2. Select a project to see details like the model, G-code files, and how to clamp the material.

![](assets/NestPad_Access_02_1-31ef0808695d.png){width=12cm}


3. Secure the material following the guide on the screen; click Clamping Method for more details.

![](assets/NestPad_Access_03_1-a839da4d9b23.png){width=12cm}




4. Check the file preview to make sure everything is correct, then click **Download** to save the G-code to the machine.

![](assets/NestPad_Access_04-fa1f689afd8f.png){width=12cm}

5. After download, click **Start Task** to begin machining.

![](assets/NestPad_Access_05-4e3e2ee0cf5b.png){width=12cm}
