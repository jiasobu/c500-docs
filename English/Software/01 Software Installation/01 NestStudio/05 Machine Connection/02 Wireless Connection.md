#### Wireless Connection

1. Connect the machine and the software to the same Wi-Fi network.
2. On the device's touchscreen, tap **Settings > Networks** to view the IP address and access code.
3. Enter NestStudio, click **Device**, click the network icon bellow the device model in the upper left corner, click **Wireless**, and enter the IP address and access code.
