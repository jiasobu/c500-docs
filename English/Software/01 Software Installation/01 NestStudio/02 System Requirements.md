### System Requirements
#### Operating System

| **Platform** | **System Requirements**                                                                            |
| :------------ | :-------------------------------------------------------------------------------------------------- |
| Windows      | Windows 10 / Windows 11, 64-bit (x64)                                                              |
| macOS        | macOS 13 Ventura or later; supports Apple M-series chips only. Intel-based Macs are not supported. |
| Linux        | Not supported                                                                                      |

#### Hardware Configuration

##### Windows

| Item            | **Minimum Configutation**                                                                                        | **Recommended Configutation**                                                                                    |
| :--------------- | :---------------------------------------------------------------------------------------------------------------- | :---------------------------------------------------------------------------------------------------------------- |
| Processor       | Intel Core i5 8th Gen, AMD Ryzen 5 3000 Series, or equivalent or higher-performance processor                    | Intel Core i5 12th Gen, AMD Ryzen 5 5000 Series, or equivalent or higher-performance processor                   |
| Graphics Card   | NVIDIA GeForce GTX 1650 (4 GB VRAM) discrete graphics card, or an equivalent or higher-performance graphics card | NVIDIA GeForce RTX 2060 (6 GB VRAM) discrete graphics card, or an equivalent or higher-performance graphics card |
| Memory          | 8 GB                                                                                                             | ≥16 GB; ≥32 GB is recommended for complex models, large toolpaths, and machining simulations.        |
| Hard Disk Space | At least 8 GB of available storage space                                                                         | SSD (solid-state drive), with at least 20 GB of available storage space                                          |

##### Mac

| **Item**        | **Minimum Configutation**                                                     | **Recommended Configutation**                                                                             |
| :--------------- | :----------------------------------------------------------------------------- | :--------------------------------------------------------------------------------------------------------- |
| Processor       | Apple M1                                                                      | Apple M2 or newer M-series chips                                                                          |
| Graphics Card   | Integrated GPU on Apple M-series chips; no additional graphics card required | Integrated GPU on Apple M-series chips; no additional graphics card required       |
| Memory          | 8 GB                                                                          | ≥16 GB; ≥32 GB is recommended for complex models, large toolpaths, and machining simulations. |
| Hard Disk Space | At least 8 GB of available storage space                                      | SSD (solid-state drive), with at least 20 GB of available storage space                                   |
