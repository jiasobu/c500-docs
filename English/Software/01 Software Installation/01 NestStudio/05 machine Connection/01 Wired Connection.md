#### Wired Connection

1. Connect the computer to the device's Ethernet port using an RJ45 network cable, then tap **Settings > Networks > Mode** on the device's touchscreen, and select **Ethernet Direct**.
2. On the device's touchscreen, tap **Settings > Networks** to view the IP address and pairing code.
3. Enter NestStudio, click **Device**, click the network icon bellow the device model in the upper left corner, click **Wired**, and enter the IP address and pairing code.
