### First Startup and machine Self-Check


When powering on the Nestworks C500 for the first time, the system provides preference configuration options, allowing users to customize settings according to their needs and optimize the overall user experience. The primary settings and functions include:

- **Language Settings**  
  Supports switching between Chinese and English.

- **machine Naming**  
  Users can customize the machine name of the C500.

- **Network Settings**  
  Configure the machine Wi-Fi connection. After connecting to the network, the system can automatically check for software and firmware updates to ensure the best user experience.  
- 
  Users can also log in to their WorkBase community account to download saved files or remotely control the machine through NestStudio on the PC side.

- **machine Self-Check Function**  
  After startup, the system provides a quick self-check function to inspect and diagnose hardware status, helping prevent machining failures and safety risks during operation.

Users may also enable or disable **Run Automatically at Startup** as needed.
