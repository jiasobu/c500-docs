### Prepare Page



Click **Prepare** to enter the ready interface, where users can precisely adjust parameters related to model size, material selection, and process settings.

![](assets/614_Ready_Page-f02704858dde.png){width=12cm}

| **No.** | **Feature**                          | **Description**                                                                                                                                                                                   |
| ------- | ------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1       | **Device Status**                    | Displays the current connection status of the device.                                                                                                                                             |
| 2       | **Connect Device**                   | If the device is not connected, users can click here to connect via wired or wireless methods.                                                                                                    |
| 3       | **Model**                            | When multiple models are imported, users can select the desired model via the drop-down menu.                                                                                                     |
| 4       | **Material**                         | Select machining materials and view CNC material instructions. When connected, scanning a material QR code automatically fills in material type and dimensions.                                   |
| 5       | **Model Size**                       | Adjust the dimensions of the imported model.                                                                                                                                                      |
| 6       | **Material Size**                    | Manually configures the dimensions of the stock material.                                                                                                                                         |
| 7       | **Stock & Model Alignment Settings** | Set the position and rotation angle of the model on the worktable.                                                                                                                                |
| 8       | **Toolpath Strategy**                | Choose from One-Click Smart Milling, Custom Settings, or adjust advanced processing parameters.                                                                                                   |
| 9       | **Create Toolpath**                  | Click to generate and preview the toolpaths for the model.                                                                                                                                        |
| 10      | **File Information**                 | Displays information about the imported or opened file, including model name and size.                                                                                                            |
| 11      | **Workbench**                        | Displays the visual representation of the machining worktable.                                                                                                                                    |
| 12      | **Stock View**                       | Displays the visual representation of the raw material stock.                                                                                                                                     |
| 13      | **Model View**                       | Displays the model view. A single model is shown in light green when no machining surface has been created. After a machining surface is created, the machining surface is highlighted in yellow. |
| 14      | **Flip Setup**                       | Sets the front face as the default machining plane, with the option for users to create a new machining plane.                                                                                    |
