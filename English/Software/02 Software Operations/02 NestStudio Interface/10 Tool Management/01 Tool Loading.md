#### Tool Loading


1. Click **Read Tool** to automatically read and register tool information when the device is connected.

2. Click **Personal Tool Library** to open the settings window for adding tools and editing tools.
   ![](https://docs.worksbase.com/neststudio/%E8%8B%B1%E6%96%87/personal-tool-library-en.png)<!-- publication-image: {width=12cm} -->

4. The tool card area displays tool type, diameter, and life information. New tool parameters can also be added in empty card slots.
