#### Import Methods

The software offers three methods to import models:

1. **Toolbar Import**: Click **Menu** (the second icon in the top toolbar), select **Import**, and choose based on the file type:
   - **Import 3D model (STL/STEP)**: A pop-up window will appear for selecting the drawing file to import.
   - **Import G-code file**: A pop-up window will appear to select the program file for import.

2. **Drag and Drop**: Drag the target file directly from the computer desktop into the software workspace to complete the import.
3. **Import Shortcut**: Press Ctrl + I on Windows or Command + I on Mac to import files.
