### Common Shortcut Functions

**Import**

Click **Import** to select the type of file to be imported:


* Import 3D Model: The user can choose to enter either the 3-Axis or 4-Axis layout interface based on machining requirements.
* Import Program: The system automatically redirects to the Device Status page.


> [!note] Notice
> Users can also drag and drop target files directly from their desktop into the software workspace for a quick import.


**Export Program**

Click **Export Program** to export the finalized data into a G-code machining file.

**Messages**

Browse various system notifications here, including official announcements, interactive updates, and competition news.
