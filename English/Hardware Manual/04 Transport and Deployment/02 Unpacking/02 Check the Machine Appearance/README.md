### Check the Machine Appearance

After confirming that the inner packaging is normal, remove the dustproof bag and the protective film on the machine surface, then check the machine appearance.

- Check whether the acrylic protective door is intact and opens and closes smoothly.
- Check whether the machine surface has scratches, dents, paint peeling, deformation, or other abnormalities.
- Check whether visible internal components are loose, damaged, or abnormal.
