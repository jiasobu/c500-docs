### Software E-Stop


The Soft E-Stop is a core safety control function integrating device lock, device unlock, and software emergency stop functions.

When the device is in an abnormal state, this function can be used to lock or unlock the device to improve machining safety.

E-Stop states are indicated by different colors:

- Green: Device standby state
- Red: Device locked state; returns to green after unlocking
- Orange: Physical E-Stop state
