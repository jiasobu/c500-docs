### File Import

The C500 supports three file import methods:

- Transfer files from a PC via NestStudio.  
- Copy files from an external USB drive.  
- Log in to an account to view and download favorite files.  

Regardless of the method, users can access the file page from the home screen to select files. The system supports common CNC formats such as `.nc`, `.gcode`, and `.txt`. Selecting a file allows previewing machining information, with options to manually delete the file or directly start machining. The interface will then switch to the machining page and await process initiation.
