#### Spindle Collet Installation and Locking

1. Select the corresponding collet according to the selected tool specification. The collet inner diameter must match the tool shank diameter.

![](../../assets/collet_tool_connection-656f90031d95.png){width=8cm}


2. Set the spindle to the tool release state.

![](../../assets/Diagram_of_collet-4e2325491365.jpg){width=8cm}

3. Place the collet on the dedicated collet installation tool, insert it into the spindle, and tighten it counterclockwise.

![](../../assets/Place_the_collet-2674fc75cafa.png){width=8cm}

> [!note] Notice  
> Regular collet maintenance is recommended. After removing the collet, clean the collet and the spindle taper bore with alcohol. After cleaning, apply a thin layer of grease to the taper bore surface, and then reinstall the collet.
