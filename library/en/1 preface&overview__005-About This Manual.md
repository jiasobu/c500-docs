## About This Manual

This manual is the official operational guide for the NestWorks C500 desktop CNC (Computer Numerical Control) Machine. It offers a complete guide to safety specifications, technical principles, programming, maintenance, and troubleshooting. As an important reference, follow all specified procedures to ensure personal safety, machine protection, and optimal performance. Keep this manual with the machine for easy access by all operators.

Read and fully understand this manual before initial installation and operation, especially the Safety chapters.
