#### Import Detection

Once a model is imported, the software automatically checks its format, size, and integrity, and displays the import results on screen:

* **Import Successful**: Displays the model name, dimensions, and other detailed parameters.
* **Import Failed**: Displays the specific error reason that caused the import to fail.

> [!note] Notice
> If a file is successfully imported but contains mesh/geometry errors, users can choose whether or not to apply the automatic repair tool.
