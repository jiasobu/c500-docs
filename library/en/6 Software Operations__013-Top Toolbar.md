### Top Toolbar


1. New Project

Click **File > New Project**, or click the **Create New Project** in the upper-right corner of the Home page to create a new project.

 2. Open Project

Click **File > Open Project** to select the file, or click the **Open** button in the upper-right corner of the Home page to browse for files.




3. Save Project

Click **Save Project** to open a pop-up window. Users can choose to save the project file to either local computer or cloud storage.

4. Save Project As

Click **Save Project As** to save the current project as a separate file with a new name or file path.
