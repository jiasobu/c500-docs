# NestPad

NestPad is an electronic touch screen mounted on the lower-right front panel of the machine. It features a 4.6-inch display with a resolution of 800×480. The screen can be rotated up to 90° in either direction, allowing adjustment of the viewing angle for convenient operation and visibility.

When using the C500 for the first time, carefully unpack the device according to the instructions. Before powering on, remove any internal securing materials, and monitor the screen for system information. All abnormal conditions and alerts are displayed directly on the NestPad interface.
