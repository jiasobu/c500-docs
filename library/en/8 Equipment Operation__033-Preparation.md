#### Preparation

- Before installation, prepare the following materials and tools: electric vise ×1, M6×18 hex socket screws ×6, and a 5 mm hex key.  

- Ensure the worktable mounting surface is clean and level, and confirm the machine is powered off or in E-Stop status.  

- Installation Position Selection:  
  The recommended installation method is Position A + tool magazine side mounting, which provides the maximum machining range for vise-clamped stock.  
  Position B + rear tool magazine mounting is recommended as an alternative configuration, although the available machining range is relatively smaller.
