#### G-code Preview

**Device Selection and Connection**  

The upper-left corner displays the currently connected device model and connection status. If the device is not connected, the interface displays a disconnected status.

**Project Information**  

Displays the model name and current machining material information, including material type and dimensions.

**Toolpath View**  

Consists of the operation strategy list and color legends:

- **Tool Information**: Displays all toolpath operations, including the Smart Milling process and individual tool operations, with machining time for each operation.

- **Color Legend**:
  
  - Dark green: Retract path
  - Light green: Reserved support
  - Red: Support to be removed
