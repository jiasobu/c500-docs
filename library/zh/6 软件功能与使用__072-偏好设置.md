### 偏好设置


偏好设置页面提供多项设备功能与系统参数配置，用户可根据实际使用需求进行个性化设置。

**表 6-12 偏好设置** <!-- mdwb:table id=232d59f1e12ce6ce -->

| 名称         | 说明                                   |
| ---------- | ------------------------------------ |
| **安全设置**   | 用于设置与设备使用安全相关的功能选项。                  |
| **CNC 设置** | 用于设置加工相关的偏好选项，如单位、自动休眠等。             |
| **延时摄影**   | 开启或关闭延时摄影功能，用于记录加工过程。                |
| **语言切换**   | 切换系统界面显示语言，支持中英文等语言显示。               |
| **音效和语音**  | 开启或关闭设备音效及语音播报功能。                    |
| **设备信息**   | 查看和管理设备信息，包括修改设备昵称、查看设备使用时长及设备唯一序列号。 |
| **导出日志**   | 将设备运行日志导出至 U 盘，便于技术人员进行问题排查。         |
