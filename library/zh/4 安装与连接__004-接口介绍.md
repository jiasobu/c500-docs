### 接口介绍

![](../../assets/External_Ports1_8-bd94b2cbb970.jpg){width=12cm}

<!-- mdwb:figure id=e2be4d335f5f8ffe -->
图 4-3 接口介绍
<!-- /mdwb:figure -->


| **序号** | **接口/组件名称**  | **功能说明**                                              |
| ------ | ------------ | ----------------------------------------------------- |
| 1      | **吸尘接口**     | 连接外部吸尘器或集尘装置，用于排出加工碎屑与粉尘，保持设备内部清洁并防止堵塞。               |
| 2      | **USB 接口**   | 用于加工程序的导入/导出、系统固件升级及设备参数备份，实现数据交互。                    |
| 3      | **E-Stop**   | 在紧急情况下立即切断设备动力电源，强制停止所有运动部件，保障人员与设备安全。                |
| 4      | **RJ45 网口**  | 用于设备联网，实现远程监控、程序传输、设备管理及生产数据采集。                       |
| 5      | **MPG 手轮接口** | 连接外接手轮，用于手动微调工作台或主轴位置，以便于对刀、坐标找正及加工调试。                |
| 6      | **电源线插口**    | 设备主电源输入接口，须连接符合额定规格的电源线。                              |
| 7      | **电源开关**     | 控制设备总电源的通断，执行开机或关机操作。                                 |
| 8      | **外部气源接口**   | 外部压缩空气输入口，为气动系统提供动力。须接入稳定气源（额定压力 0.6MPa，最大压力 0.8MPa）。 |

| **序号** | **接口/组件名称** | **功能说明**                                                     |
| ------ | ----------- | ------------------------------------------------------------ |
| 9      | **加工区气源接口** | 为主轴吹气、刀具清洁或气动夹具提供压缩空气，保证加工过程的稳定性与工作区的清洁度。                    |
| 10     | **第四轴接口**   | 连接外部旋转轴工作台，实现工件的分度或多面连续加工，扩展设备的加工能力与工艺范围。也可连接外部虎钳，实现装夹方式多样化。 |
| 11     | **右侧监控摄像头** | 实时监测机器加工过程，防止加工意外发生。                                         |
