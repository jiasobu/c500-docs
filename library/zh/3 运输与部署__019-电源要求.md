### 电源要求

> [!caution] 注意  
> 若设备由寒冷环境搬运至温暖环境，请勿立即通电，建议静置 4～6 小时，待冷凝水完全挥发后方可通电使用。


设备接入电源前，请确认供电线路满足以下要求：

**表 3-3 电源要求** <!-- mdwb:table id=9d46fe32937e793b -->

| 项目   | 要求                       |
| ---- | ------------------------ |
| 输入电压 | 110 ~ 240 VAC            |
| 频率   | 50 / 60 Hz               |
| 总功率  | 1.6 kW                   |
| 供电回路 | 建议使用独立供电回路               |
| 漏电保护 | 应安装额定动作电流不小于30 mA的漏电保护装置 |
| 接地要求 | 电源插座必须可靠接地               |



> [!danger] 危险
> 严禁使用无接地或接地不良的电源插座，否则可能导致触电危险、设备损坏或控制系统受到干扰。
