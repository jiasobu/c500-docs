### 安全操作限制

- 禁止擅自屏蔽、短接、改装设备的防护门联锁、急停按钮、限位开关等安全功能，该行为将直接导致质保失效，由此引发的安全事故与设备损坏由使用方承担全部责任；
- 设备运行过程中，严禁打开防护门、将身体任何部位伸入加工舱内，严禁触碰主轴、排屑螺杆、运动轴等旋转或运动部件；
- 禁止在无专业防护措施的情况下进行加工操作，操作人员必须佩戴符合标准的安全护目镜，高噪音加工场景必须佩戴听力防护装备；
- 禁止在设备运行过程中进行刀具更换、工件装夹、清洁维护等操作，所有相关操作必须在按下急停按钮、切断设备主电源后方可进行；
- 未成年人不具备操作资质，禁止上机操作，无相关专业知识与操作培训的人员禁止独立操作设备；
- 严禁设备在无人值守状态下进行高风险加工，无人值守加工必须完成充分的程序校验、安全防护与风险评估，且仅可在设备安全功能全部正常启用的状态下进行。
- 严禁屏蔽、拆除、改装或绕过防护门、急停按钮、门检装置等安全保护功能。违反上述要求导致设备故障、人员伤害、财产损失或其他安全事故的，整机质保自动终止，相关后果由使用方自行承担。
