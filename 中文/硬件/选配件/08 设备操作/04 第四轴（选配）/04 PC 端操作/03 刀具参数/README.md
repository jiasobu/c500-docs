#### 刀具参数

**表 8-1 刀具参数** <!-- mdwb:table id=82fbb825c6e83a2e -->

| 参数           | 说明                                                                                                                                                              |
| ------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 下刀角度         | 包括 90° 垂直下刀、5° 斜度下刀和 20° 斜度下刀三种。<br>90° 垂直下刀：刀具垂直扎入毛坯，适合浮雕大面积平面开粗，不易断刀。<br>5° 斜度下刀：刀具以小角度斜向进刀，切削冲击更小，适合薄浮雕纹路加工。<br>20° 斜度下刀：刀具以较大角度斜向进刀，可减少刀具负载，适合高深度浮雕和硬质材料加工。 |
| 安全高度         | 刀具抬刀后的安全移动高度，可防止移动过程中碰撞毛坯。                                                                                                                                      |
| 主轴速率（RPM）    | 主轴每分钟转速。刀具直径越小，建议转速越高。                                                                                                                                          |
| 进给速率（mm/min） | 刀具水平浮雕走刀速度。数值越大，加工越快，表面粗糙度越高。                                                                                                                                   |
| 下刀速率（mm/min） | 刀具垂直进入毛坯的速度。                                                                                                                                                    |
| 每层切割深度（mm）   | 单次下刀的切削厚度。                                                                                                                                                      |
| 步进量（mm）      | 相邻两道刀路的横向间距。数值越小，浮雕纹路越光滑，计算刀路耗时越长。                                                                                                                              |


> [!note] 提示  
> 必须至少装配 1 把刀具，否则无法生成浮雕刀路。粗加工和精加工分开装配两把刀具时，加工效果更佳。
