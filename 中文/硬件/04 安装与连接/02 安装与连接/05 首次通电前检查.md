### 首次通电前检查

| 序号  | 检查项目       | 检查要求                                          |
| --- | ---------- | --------------------------------------------- |
| 01  | 安装环境       | 设备放置在室内干燥、清洁、照明充足的区域，周围无易燃液体、气体及粉尘风险。         |
| 02  | 设备放置       | 设备放置平稳，支撑面平整，承载能力符合设备安装要求。                    |
| 03  | 机身外观       | 机身无明显运输损伤、变形或松动。                              |
| 04  | 防护门        | 防护门无开裂、变形或松动，开合顺畅。                            |
| 05  | 外部运输固定钣金   | 四组主机运输固定钣金及对应固定螺丝已拆除。                         |
| 06  | 主轴与工作台固定钣金 | 主轴与工作台之间的运输固定钣金已拆除。                           |
| 07  | 主轴侧螺丝      | 随附的主轴侧钣金固定螺丝已安装回对应孔位。                         |
| 08  | 腔体内包装箱及附件  | 包装箱、散放附件及工具已从腔体和工作台移出。                        |
| 09  | 其余运输防护材料   | 可在断电状态下安全取出的珍珠棉、垫片、胶带及运输辅料已清理。主轴下方垫块除外，见表后说明。 |
| 10  | 气嘴保护套      | 设备内部气嘴及主轴气嘴保护套已拆除。                            |
| 11  | 主轴夹刀位置保护套  | 主轴夹刀位置保护套已拆除。                                 |
| 12  | 部件保护膜      | 摄像头、照明、探针及防护门等部位的保护膜或贴纸已拆除。                   |
| 13  | 刀库运输防护     | 刀库表面的固定胶带及保护膜已拆除。                             |
| 14  | 输入电源       | 供电电压、频率与设备铭牌要求一致。                             |
| 15  | 接地         | 使用有效接地的插座，接地端子完整。                             |
| 16  | 电源线与插头     | 电源线及插头无破损、变形或其他可见异常。                          |
| 17  | 线缆布置       | 可见线缆无夹挤、拉扯，不妨碍设备运动。                           |
| 18  | 配件连接       | 配件已在设备关机状态下按安装说明接入，连接牢固；禁止在设备通电状态下插拔配件。       |
| 19  | 刀库固定       | 刀库定位正确，固定螺丝已紧固。                               |
| 20  | 刀库连接       | 刀库连接件已按安装说明连接并锁紧。                             |
| 21  | 气管         | 气管无可见损伤或夹挤，接口连接牢固。                            |
| 22  | 水箱固定       | 水箱放置稳定，加液口盖已拧紧，通气阀朝上。                         |
| 23  | 水箱液位       | 液位在刻度范围内，铜滤芯位于液面以下。                           |
| 24  | 水管         | 水管无破损或弯折，接口连接牢固。                              |
| 25  | 工作区域       | 腔体和运动区域内无散放工具、附件或其他明显阻挡物。                     |
| 26  | 急停按钮       | 按钮无可见损伤，位置清楚且便于触及。                            |
