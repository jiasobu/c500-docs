#### L型定位治具和 OK夹

**安装前准备**  

请准备以下材料与工具：L 型定位治具 ×1、OK 夹 ×2、φ4×10 定位销 ×2、M6×12 / M6×20 内六角螺钉 ×3、M6×20 T 型螺栓 ×4、M6 法兰螺母 ×4、5 mm 内六角扳手、10 mm 外六角扳手

> [!note]  
> T 型螺栓用于拉紧固定夹具套装。使用时，将 T 型卡头顺向放入工作台面的卡槽，旋转 90°后再用螺母锁紧。

**安装步骤**  

1. 按图示放置 L 型定位治具和 OK 夹。  
2. 拧紧或松开 OK 夹顶紧螺丝，完成工件装夹或拆卸。应对坯料尺寸稳定，需要快速拆装，加工应力不大的加工场景。
