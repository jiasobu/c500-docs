# 夹具套装使用指南

本组件主要用于小型板材或五金件等轻薄工件的固定和装夹，确保工件在雕刻过程中不松动、不偏移。

## 材料

夹具套装可用于以下材料：

- 虎钳难以装夹的超大方形材料。
- PCB、金属板、木板等薄板材料。

![](assets/01-Materials-eba574bbfa88.png){width=12cm}

可根据工件尺寸和加工负载选择装夹方案：

| 装夹方案 | 适用场景 |
| --- | --- |
| L 型定位治具和 OK 夹 | 坯料尺寸稳定、需要快速拆装、加工应力较小的场景 |
| L 型定位治具和侧夹 | 坯料尺寸较小、需要快速拆装、加工应力较小的场景 |
| 平面板夹 | 坯料尺寸较大、加工应力较大的场景 |

## 分中

分中是机器获取坯料尺寸信息的重要步骤，在选材和装夹时务必要为探针留出探测位置。

### 使用 L 型治具时

- 如确定左下角为零点，则只需测量 Z 向高度。
- 如确定工件中心为零点，则需要测量 X、Y、Z 的位置。

![](assets/Centering_Probing_Area_AB-6331e75c8c95.png){width=12cm}

### 使用平面板夹时

以以下这种装夹方式为例：

- 材料的四个方向都需要测量。
- 任意选一点测量 Z 轴高度。

![](assets/Centering_Probing_Area_C-bc74a7421023.png){width=10cm}

## OK 夹

### 安装前准备

准备以下材料与工具：

- L 型定位治具 ×1
- OK 夹 ×2
- φ4×10 定位销 ×2
- M6×12 或 M6×20 内六角螺钉 ×3
- M6×20 T 型螺栓 ×4
- M6 法兰螺母 ×4
- 5 mm 内六角扳手
- 10 mm 外六角扳手或套筒扳手

### OK 夹安装

1. 将 T 型螺栓和法兰螺母预装到 OK 夹上。
2. 调整 T 型螺栓方向，以便推入 T 型槽。
3. 将 OK 夹放入 T 型槽并推至合适位置。

![](assets/04-OK_Clamp_Installation-aa9b1b0a4770.png){width=10cm}

### L 型治具位置与限制

L 型定位治具共有两种安装位置可选，分别为激光雕刻和 CNC 加工所需位置。

以下示例均以 CNC 加工为例。

- 激光雕刻 4th-Axis
- CNC Vise-B

共有如下两种规格，用户可按照工件所需避让空间选择其中一种进行安装。

![](assets/AB-06980c2eb78f.png){width=10cm}

![](assets/workpiece-f62e979c950f.png){width=10cm}

### 治具与夹具定位

1. 安装 L 型治具定位销。
2. 安装 L 型治具内六角螺丝。

![](assets/12-80605df99bf9.png){width=12cm}

3. 将坯料放置在工作台上，坯料两边需紧贴 L 型定位治具内侧，确保夹具滑块尽可能紧贴工件表面。
4. 将 T 型螺栓旋转 90°。

![](assets/34-44ad907b0b82.png){width=12cm}

### 最终紧固

1. 使用外六角套筒扳手上紧 OK 夹法兰螺母。
2. 使用内六角扳手上紧 OK 夹顶紧螺丝。

![](assets/Final_Tightening-a9ddad54f7db.png){width=10cm}


### 安装完成示例

下图展示 L 型定位治具和 OK 夹在 C500 工作台上的整体安装效果。

![](assets/L-Shaped_OKClamp-fa0c0d075092.png){width=10cm}

## 平面板夹

平面板夹应用于坯料尺寸较大、加工应力较大的加工场景。

平面板夹有多种使用方式，供用户依据工件和坯料规格自由选择。

### 安装前准备

准备以下材料与工具：

- 平面板夹 ×4
- M6×25 或 M6×35 T 型螺栓 ×8
- M6 法兰螺母 ×8
- 自制辅助垫块 ×2
- 5 mm 内六角扳手
- 10 mm 外六角扳手或套筒扳手

安装时，用户需根据所要加工的工件自备辅助垫料。预留空间大的一侧总是应该对应较厚的件，无论其所对应的是需加工工件还是辅助垫料。

![](assets/first-e8573b4d5657.png){width=10cm}


### 安装

1. 平面板夹和工件、辅助垫料的贴合面都应尽可能保证面接触。
2. 移动夹板，使螺栓进入夹板滑槽的侧向定位半孔孔位，螺栓位置靠近工件一侧。
3. 安装到位后将 T 型螺栓旋转至 90°，并使用外六角套筒扳手拧紧所有法兰螺母。

![](assets/second-bade256ab095.png){width=12cm}

如横向使用平面板夹，T 型螺栓位置则应靠近平面板夹的两端。

![](assets/third-027fafe31e1b.png){width=10cm}

### 安装完成示例

下图展示平面板夹、坯料和辅助垫块在 C500 工作台上的整体安装效果。

![](assets/Flat_Panel_Clamp-f04edf6067d0.png){width=10cm}

| 序号 | 名称 |
| --- | --- |
| 1 | 平面板夹 |
| 2 | 坯料 |
| 3 | 辅助垫块 |

> [!caution] 注意
> - 固定螺丝的锁紧力度应适中，避免过度锁紧导致工作台、夹具或夹板螺纹损坏。
> - 夹板安装完成后，应确认两侧保持平行，避免工件受力不均或加工位置偏移。
> - 装夹工件时，应避免夹板直接损伤工件表面；必要时在接触位置增加软布或防护垫。
> - 开始加工前，确认夹具、紧固件和工件均已可靠固定，且不会与主轴、刀具或探针的运动路径发生干涉。

## 纵向垫板

如用户有对零件过切的需求，可以使用套件中所提供的纵向垫板。

![](assets/13-Sacrificial_Board_X-Axis-f1465922b80e.png){width=12cm}

1. 使用沉头螺丝将纵向垫板安装在工作台上。垫板孔位带有 M6 螺纹，L 型治具、夹具、平面板夹均可由 M6 内六角螺丝直接安装在纵向垫板上。

![](assets/1-410b72921abf.png){width=10cm}

2. 将 L 型定位治具孔位对准纵向垫板上的 CNC 对应孔位，插入定位销。
3. 安装 L 型定位治具内六角螺丝。

![](assets/23-4f9cba5b1218.png){width=12cm}

4. 将 OK 夹使用 M6 螺丝直接安装在垫板上的合适位置。
5. 上紧 OK 夹顶紧螺丝。

![](assets/45-b7863389520e.png){width=12cm}
