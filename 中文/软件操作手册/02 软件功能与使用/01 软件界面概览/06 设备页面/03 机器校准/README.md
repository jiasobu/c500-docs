#### 机器校准


点击设备界面左侧菜单栏的**机器校准**，进入设备界面中的机器校准界面。该界面分为**设备信息**与**设备校准**两个子界面，用于查看设备状态、参数及执行校准操作。

![](../../../../../../assets/6164-74f3ab6ff453.png){width=12cm}

<!-- mdwb:figure id=3809e6ebf799548e -->
图 6-9 机器校准
<!-- /mdwb:figure -->


| **序号** | **子界面** | **功能模块及说明**                                                                                                                                 |
| ------ | ------- | ------------------------------------------------------------------------------------------------------------------------------------------- |
| 1      | 设备信息    | **设备信息**：查看设备型号、连接方式、累计工作时长及固件版本，可设置启动回零。<br>**状态参数**：查看主轴核心状态、实际进给与主轴速度、机械坐标与工件坐标、机器状态、当前刀号及G-code执行情况。<br>**机床参数**：查看机床参数，包括主轴最高转速、机床结构等。 |
| 2      | 设备校准    | **设备诊断**：检测设备状态及各部件功能。<br>**设备校准**：调整设备精度及相关参数，如探针分中坐标、主轴分中坐标等。                                                                             |
