### NestPad 界面概览

NestPad 提供直观可靠的本地操作界面，无需连接 PC 即可完成文件导入、原点设置、加工监控及配件控制等核心操作。

**表 6-1 NestPad 界面概览** <!-- mdwb:table id=58e3221f96d3aeb7 -->

| 序号  | 功能               | 说明                                                        |
| --- | ---------------- | --------------------------------------------------------- |
| 1   | **Files（文件）**    | 浏览系统本地或 U 盘中的程序文件并启动加工。联网并登录账号后，可同步访问及下载收藏的程序。            |
| 2   | **Status（状态）**   | 实时显示设备各子模块状态，包括照明、清洁、冷却系统监控，以及加工倍率调节与温度监测。                |
| 3   | **Control（控制）**  | 主轴运动控制。支持手动操作 **XYZ** 轴移动及运动参数调节，提供快速回零、重置主轴及手动设置工作原点等功能。 |
| 4   | **Origin（工作原点）** | 引导式设置工作原点。指引用户放置工件、自动执行分中（分片），并最终创建新的工作坐标系。               |
| 5   | **Tools（刀具）**    | 刀具管理，包括换刀、还刀操作，支持快速读取 RFID 刀具信息，可设置主轴夹头和开关刀库。             |
| 6   | **Messages（日志）** | 记录设备异常信息，并提供解决方案。                                         |
| 7   | **Setting（设置）**  | 包含设备基础设置和用户偏好设置。                                          |
