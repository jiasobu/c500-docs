#### 设备校准

可进行设备精度校准与参数调试，修正定位偏差，提高加工安全性与加工精度。

![](https://docs.worksbase.com/neststudio/%E4%B8%AD%E6%96%87/device-machinecalibration-devicecalibration-zh.png)<!-- publication-image: {width=12cm} -->


**设备诊断**  

| **功能**   | **说明**                                   |
| :---- | :------------------------------------ |
| 安全与防护类 | 开启 **安全模式** 后启用设备安全保护功能，建议加工过程中保持开启状态。  |
| 加工辅助类 | 控制空气净化、真空吸盘、主轴清洁、冷却液、台面清洁及加工后清洁台面等功能。<br>开启后，可提升排屑与冷却效果。                              |
| 照明与视觉类 | 控制照明灯及描边激光，用于工件观察与装夹定位校验。 |
| 机构与工具类 | 控制刀库开合、执行刀库门角度复位操作。<br>刀库门角度复位：通过自动校准补偿刀库位置偏差，改善因长期使用产生的位置偏差，从而避免刀库门关闭不到位等异常情况。 |


**设备校准**  

- **探针**：可手动调整探针上移、下移位置，并进行探针定位误差修正，以提升分中精度。探针校准的准备条件和完整操作流程请参阅 [探针校准](/zh/c500/maintenance-guide/probecalibration)。

  > [!caution] 注意
  > 
  > 分中与校准过程中，请勿触碰工件或探针。
  
- **L 型夹具**：当使用 L 型夹具分中前，可先校准 L 型夹具位置基准。校准时工作台面不可放置工件。
