#### 自定义工序


三轴标准件支持创建自定义工序，可在工艺树点击加工面（顶面/底面）设置下的 3D 文件名或一级工序节点创建。

自定义工序提供钻孔、铣牙、倒角、轮廓和区域五种工艺类型，可根据实际加工需求选择对应类型，并配置刀具及加工参数，生成相应的刀具路径。


**工艺类型**

|   **工艺类型**      |        **说明**                 |
|   :-------------|   :-------------------------------------------------------------------------- |
|   钻孔          |       用于孔类特征的加工，支持钻孔、扩孔及锪孔（沉孔）等加工方式。           |
|   铣牙          |       用于螺纹铣削加工，使用螺纹铣刀加工内螺纹或外螺纹。           |
|   倒角          |       沿零件棱边或轮廓生成倒角刀具路径，用于去除锐边毛刺或加工倒角面。           |
|   轮廓          |       基于 2D 轮廓生成刀具路径，支持开放轮廓和闭合轮廓，适用于轮廓粗加工或精加工。           |
|   区域          |       针对选定区域生成加工刀具路径，支持平行加工策略，并可根据需要设置是否避让岛屿或障碍物。           |


**操作步骤**

1. 在工艺树点击加工面设置下的 3D 文件名或一级工序节点，点击鼠标右键选择 **创建工序**。
2. 在顶部工艺类型中选择所需的类型。
   ![](https://docs.worksbase.com/neststudio/%E4%B8%AD%E6%96%87/create-operation1-zh.png)<!-- publication-image: {width=12cm} -->
  
3. 点击右侧参数面板中的几何体选择框。 

4. 在模型中选择需要加工的几何体或轮廓。

5. 设置刀具类型、刀具参数及相关加工参数。

6. 参数设置完成后，点击 **确定**。
   ![](https://docs.worksbase.com/neststudio/%E4%B8%AD%E6%96%87/create-operation2-zh.png)<!-- publication-image: {width=12cm} -->


7. 在左侧工艺树中选中已创建的自定义工序，点击鼠标右键选择 **仿真预览**，查看对应的刀具路径及加工效果。
   ![](https://docs.worksbase.com/neststudio/%E4%B8%AD%E6%96%87/create-operation3-zh.png)<!-- publication-image: {width=12cm} -->
