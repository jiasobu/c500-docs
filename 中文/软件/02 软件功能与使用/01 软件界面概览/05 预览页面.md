### 预览页面


点击主页顶部工具栏中央的**预览**进入预览界面。查看生成的刀路效果、策略参数及加工路径，并支持直接加工或导出 G-code 文件。

![](https://docs.worksbase.com/neststudio/%E4%B8%AD%E6%96%87/previewpage-zh.png)<!-- publication-image: {width=12cm} -->


| **序号**  | **功能**           | **说明**                                                    |
| :--- | :------------ | :----------------------------------------------------- |
| 1   | **设备连接状态**   | 显示当前设备连接情况。若设备未连接，可点击右侧图标通过有线或无线方式连接设备。               |
| 2   | **加工面**        | 支持按加工面（顶面/底面）切换查看刀路，检查不同加工面的刀路规划情况。                                   |
| 3   | **预览设置**       | 打开 **材料去除** 开关，模拟实际加工过程中的材料去除效果，直观呈现最终加工结果。 |
| 4   | **工序颜色**     | 仿真预览中的工序颜色与左侧工艺树中对应工序的颜色标注，便于区分不同工序。                                             |
| 5   | **刀路检测报告** | 右侧展示刀路检测报告。支持检查刀路是否存在碰撞、过切或欠切等风险，辅助评估刀路安全性与加工结果的精细度。   |
| 6   | **刀具路径**      | 显示刀具加工路径。                                            |
| 7   | **预览加工视频**   | 设置刀路视频播放速度，默认 1x，可选择 0.25x、0.5x、2x、4x、8x、16x 或 32x。                                    |
| 8   | **加工**       | 在设备连接状态下，点击开始加工。                                       |
