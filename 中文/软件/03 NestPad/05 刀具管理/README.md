## 刀具管理

| **序号** | **名称**     | **功能说明**                                                                                                |
| ------ | ---------- | ------------------------------------------------------------------------------------------------------- |
| 1      | **更换刀具**   | 页面显示当前主轴刀号及 T1–T5 刀位信息。选中刀号点击“取刀”，主轴自动取刀并前往对刀仪校准，根据刀具长度计算 Z 轴坐标；点击“还刀”将刀具归还至对应刀位                        |
| 2      | **刀具信息获取** | 点击“扫描刀具”快速读取 RFID 刀具信息并同步至界面。读取成功显示绿色边框及尺寸类型；无信息则显示空白；无刀状态下刀位数字置灰。点击 **开始扫描** 将重新扫描刀具， 点击 **确认** 可覆盖旧信息 |
| 3      | **刀库位置检查** | 更换刀库位置并校准后，选中刀位点击 **检查刀具** ，主轴将移动至刀位正上方 10mm 处，供用户观察主轴与刀具是否对齐                                           |
| 4      | **刀库门控制**  | 单次点击按钮，手动操控刀库门的开启或关闭                                                                                    |
| 5      | **夹头设置**   | 点击 **松开** 打开夹头取刀，点击 **夹紧** 夹紧刀具，点击 **对刀** 前往对刀仪校准Z轴                                                     |
