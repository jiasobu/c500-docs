### 全自动分中

1. 在首页点击 **原点** 进入工件原点设置页面。

2. 选择 **探针**，点击 **确认**。

![](https://docs.worksbase.com/nestpad/%E4%B8%AD%E6%96%87/%E5%88%86%E4%B8%AD%E6%A8%A1%E5%BC%8F-zh.png)<!-- publication-image: {width=12cm} -->

3. 使用右侧主轴运动面板将主轴移动到工件上方，确保工件位于画面中心，点击 **下一步**。

![](https://docs.worksbase.com/nestpad/%E4%B8%AD%E6%96%87/%E5%85%A8%E8%87%AA%E5%8A%A8%E5%88%86%E4%B8%AD1-zh.png)<!-- publication-image: {width=12cm} -->

4. 根据实际情况选择识别方式，获取工件尺寸后，点击 **开始**。

![](https://docs.worksbase.com/nestpad/%E4%B8%AD%E6%96%87/%E5%85%A8%E8%87%AA%E5%8A%A8%E5%88%86%E4%B8%AD2-zh.png)<!-- publication-image: {width=12cm} -->

| **识别方式**   | **说明**                                  |
| :-------- | :------------------------------------------------|
| 扫描二维码  | 扫描工件上的二维码，可直接获取工件的长宽高                           |
| 扫描工件   | 自动识别工件轮廓与尺寸                            |
| 手动框选   | 手动框选工件尺寸大小                            |

5. 按照界面提示执行自动分中，当界面提示“分中完成”时，同步显示 X / Y / Z 轴原点坐标。
