### 清点配件

1. 设备搬运至预定安装位置后，缓慢打开设备防护门，检查防护门是否存在开裂、变形、松动等异常，并确认开合顺畅。

![](../../../../../assets/05_2-5e61aaad0784.png){width=10cm}

2. 检查设备机身表面是否存在划痕、磕碰、掉漆、变形等外观损伤，确认设备主机外观及内部初始防护状态完好。

3. 完成设备外观检查后，按照由上至下、由外至内的顺序依次取出设备内部配件及包装箱。

4. 取出设备前侧的珍珠棉垫块及前侧配件包装箱。

![](../../../../../assets/01-cb0ca0aa0073.png){width=10cm}

5. 取出工具包、标准配件及维护耗材等随机附件。

![](../../../../../assets/02-7d9dd8c85c7a.png){width=10cm}

6. 取出设备内部及工作台上的原材料包装箱和相关附件。

![](../../../../../assets/03-ced2c2af22fb.png){width=10cm}

7. 将所有配件统一整理摆放，并检查包装是否存在破损、受潮或变形等情况。
8. 逐项核对配件种类及数量，确认无缺失、损坏或错配情况。


设备随机配件主要分布于以下包装箱中。开箱后，请根据各包装箱内容逐项清点，确认配件无缺失、无损坏。
