## 防护门检测装置

**位置与功能**

防护门左右两侧各安装一个门磁传感器，用于检测防护门开关状态。
当门被打开时，系统将执行以下保护动作：

**表 2-2 防护门检测装置** <!-- mdwb:table id=fb28060380044cd8 -->

| 序号  | 保护动作     | 说明                               |
| --- | -------- | -------------------------------- |
| 1   | 轴运动限速    | 将 X、Y、Z 轴的手动移动速度限制为 1000 mm/min。 |
| 2   | 禁止主轴旋转   | 切断主轴驱动并停止刀具旋转，防止人员触碰受伤。          |
| 3   | 切断激光输出   | 关闭激光，避免激光外泄造成人身伤害。               |
| 4   | 停用喷淋系统   | 关闭 MQL 喷淋，防止油雾或切削液向外喷洒。          |
| 5   | 关闭吹气风扇   | 停止气嘴吹扫和排屑风扇运行，避免碎屑向外飞溅。          |
| 6   | 停止排屑螺杆运动 | 停止排屑螺杆运行，避免人员接触运动部件造成伤害。         |


**使用场景**


1. 工件装夹作业：加工开始前，打开防护门，放置并固定工件；
2. 分中与对刀操作：执行工件分中及零位确认工作；
3. 刀具更换操作：更换主轴刀具，或在刀库内拆装、校准刀具；
4. 切屑清理作业：临时清理工作台及夹具处堆积过多的切屑；
5. 停机状态检查：程序停止后，打开防护门，观察工件加工状态、区域积屑情况及刀具磨损情况。



**复位流程**

1. 关闭防护门，确保门磁传感器检测到门已闭合。
2. 在控制软件中点击 **清除报警**。
3. 设备恢复待机状态，可执行后续操作。
