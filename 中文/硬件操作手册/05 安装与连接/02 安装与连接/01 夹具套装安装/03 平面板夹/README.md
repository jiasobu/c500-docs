#### 平面板夹

**安装前准备**  

安装前，请准备以下材料与工具：平面板夹 ×4、M6×25 / M6×35 T 型螺栓 ×8、M6 法兰螺母 ×8、自制辅助垫块 ×2、5 mm 内六角扳手、10 mm 外六角扳手

**安装步骤**  

1. 按图示放置平面板夹及辅助垫块。  
2. 拧紧或松开平面板夹压紧螺母，完成工件装夹或拆卸。 应对坯料尺寸较大，加工应力较大的加工场景。 

![](../../../../../../assets/Flat_Panel_Clamp-f04edf6067d0.png){width=10cm}

| 序号  | 名称   |
| --- | ---- |
| 1   | 平面板夹 |
| 2   | 坯料   |
| 3   | 辅助垫块 |




> [!caution] 注意
> - 固定螺丝锁紧时应力度适中，避免过度锁紧导致工作台或夹板螺纹损坏。  
> - 夹板安装完成后，应确认两侧保持平行，以防工件受力不均或加工位置偏移。  
> - 装夹工件时，应避免夹板直接接触工件表面；建议在接触位置加垫软布或防护垫，以防工件表面划伤。
